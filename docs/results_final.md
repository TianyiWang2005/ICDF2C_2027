# 最终实验结果（用于论文写作）

> **这是论文应引用的版本。** 设置：TAB 全部 1,268 篇减去 2 篇 few-shot 示例 = **1,266 篇**；SAGE 由 DeepSeek（`deepseek-flash`）按官方代码复现；QI 由 2-shot LLM 抽取，并按 TAB 标注指南做规则后处理（`pipeline/qi_filter.py`）；主方法 = 风险图 + 迭代贪心覆盖（最稀有优先），order 2 / order 3 两个隐私等级；k₀ ∈ {2, 5, 10}，除注明外 k₀ = 5。
> 数据：`results/full_filtered/`、`results/qi_filter/`、`results/full/`（SAGE 与原文的评估结果在两轮之间通用）。演变过程见 [`results_full.md`](results_full.md)，指标解释见 [`results_analysis.md`](results_analysis.md)。

## 1. 论文的核心结论

| 研究问题 | 结论 | 关键数字 |
|---|---|---|
| RQ1：SAGE 输出是否存在隐藏 QI？ | 存在，且普遍 | 97.3% 的文档可被两个 QI 的组合在语料中定位；81.7% 的 QI 取值只出现在一篇文档中（后处理前统计） |
| RQ1′：SAGE 的自我审查可靠吗？ | 不可靠 | 判为 safe 的文档原文 QI 残留 3.5%，判为不 safe 的反而只有 0.7% |
| RQ2：只处理单个 QI 够吗？ | 不够 | 按单值稀有度泛化后，94.8% 的文档仍可被组合定位 |
| RQ2′：关键在泛化多少，还是泛化哪些？ | 泛化哪些 | 同样泛化步数随机分配，风险仍有 90.1%；ours 降到 0% |
| RQ3：隐私效果 | 在所检查的阶数内消除组合风险 | order 3：两两、三元组风险 0%，四元组 8.8%，五元组 16.3%（SAGE 为 95.4% / 92.3%）；原文 QI 残留 3.07% → 0.69% |
| RQ3′：代价 | 信息损失 59–71%；RAG 问答 −4.7 分 | 问答得分 SAGE 49.2 → ours 44.6，95% CI [−6.8, −2.5] |
| RQ4：方法组件 | 框架起作用，选点规则影响很小 | 各选点规则信息损失差距 ≤ 2 个百分点；QI 后处理把效用损失减半 |

## 4. 原文 QI 残留率（LLM 判断，k₀ = 5）

| 版本 | 残留率 | 至少残留一个的文档 |
|---|---|---|
| SAGE | 3.07% | 30.2% |
| ours，order 3（后处理前） | 0.55% | 11.6% |
| **ours，order 3（最终）** | **0.69%** | 13.4% |

后处理把通用机构名、法律程序等保留下来，残留率只上升 0.14 个百分点，主要集中在 DEM（7.7%）和 MISC（8.1%），即 QI 抽取召回较低的类型。

## 5. RAG 问答效用（TAB-200 题库，1,000 题）

| 版本 | 问答得分 | 检索命中 @2 | 相对 SAGE（95% CI，配对 bootstrap） |
|---|---|---|---|
| 原文 | 79.5 | 68.4 | +30.2 [+27.0, +33.7] |
| SAGE | 49.2 | 54.7 | — |
| ours，order 2（最终） | 44.6 | 51.3 | −4.7 [−7.0, −2.5] |
| **ours，order 3（最终）** | **44.6** | 51.0 | **−4.7 [−6.8, −2.5]** |
| 全部抹掉（后处理后） | 44.6 | 50.8 | −4.7 [−6.9, −2.4] |
| ours，order 3（后处理前） | 39.6 | 48.9 | −9.7 [−12.2, −7.1] |

- **后处理的作用显著**：ours order 3 后处理后比后处理前高 +5.0 分 [+3.0, +7.0]，效用损失减半。
- **主要的效用损失来自 SAGE 本身**（−30.2 分），我们的方法在此基础上再损失 4.7 分。
- **ours 与"全部抹掉"问答得分相同**（差 0.0 [−1.1, +1.2]）：问答效用取决于"哪些内容被当作 QI"（由后处理决定），而不取决于泛化到哪一层。ours 相对"全部抹掉"的优势体现在信息损失（59–71% 对 100%）：保留了 "1990s"、"a higher court" 这类中间层级，供需要时间或机构类别的下游使用。论文中应如实说明这一点。
- 文件：`results/full_filtered/utility_summary.json`、`utility_tab200_*.csv`。

## 6. 方法组件的验证

| 组件 | 验证 | 结果 |
|---|---|---|
| QI 抽取（2-shot LLM + 后处理） | TAB test 原文，对比人工标注（127 篇 × 全部标注者） | DIRECT 召回 97.8%，QUASI 召回 87.6%，字符 F1 76.6（后处理前 74.5） |
| few-shot 数量 | 0 / 2 / 4 / 8 个示例 | 2 个已饱和（QUASI 召回 76.5 / 87.8 / 88.5 / 84.5） |
| QI 抽取在 SAGE 文本上 | 用残留 QI 间接估计 | 召回 87.2% |
| 后处理规则 | TAB 人工标注统计 | 不含专名的机构仅 4.5% 被标注者遮蔽（含专名 48.1%） |
| SAGE safe 标签 | 分组对比 | 与真实风险无关 |
| 语料规模 | 254 篇 vs 1,266 篇 | 结论一致；信息损失随规模下降 |

## 7. 局限性（论文中应写明）

1. 风险定义只覆盖抽取出的显式 QI；抽取召回约 87%，DEM、MISC 较低。
2. 只保证所检查阶数内的 k-匿名，更高阶组合仍有风险（第 3 节）。
3. "案情模式本身"可识别案件（如 Heinisch v. Germany），以及链接回 HUDOC 的攻击，不在本文威胁模型内（留给后续工作）。
4. 后处理会放过少量被 TAB 标注者视为需要遮蔽的通用名（机构约 4.5%、法律程序约 20%）。
5. SAGE 为复现版本，LLM 为 DeepSeek，与原论文（GPT-3.5）不同。
6. 残留率和效用评分由 LLM 判断；人工验证（κ）材料已准备（`data/human_eval/`），尚待标注。
