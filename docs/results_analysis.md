# 实验结果与分析（可行性验证版，254 篇）

> 运行日期 2026-11-25。数据：TAB dev + test 共 254 篇 ECHR 判决书。LLM：DeepSeek（`deepseek-chat`，实际返回 `deepseek-flash`）。
> 全部 LLM 调用总费用约 9 美元，缓存在 `data/llm_cache/`，重跑可以零成本复现。
> 框架和每一步的说明见 [`framework.md`](framework.md)。

## 0. 一句话结论

**框架可行。** 在 SAGE 改写后的语料中：

- **隐藏 QI 问题确实存在**：97.2% 的文档能通过两个 QI 的组合在语料中被唯一定位。
- **我们的方法能消除它**：两两组合风险降到 0%；order 3 时三元组风险也降到 0%。
- **代价**：RAG 问答效用没有统计上可测的下降（相对 SAGE 为 −0.2 到 −1.2 分，95% 置信区间都包含 0）。
- **主要弱点**：QI 信息损失偏高（60–77%）。分析显示，这主要来自语料太小（254 篇）和严格的风险定义，而不是方法本身。
- **稳健性**：SAGE 判为不 safe 的 32 篇也纳入了（SAGE 官方代码同样保留它们）；只用 safe 文档重跑，结论不变。SAGE 的 safe 标签与真实风险无关。

### 3.2 结论

**发现 3：隐藏 QI 问题的直接证据。** 在 SAGE 输出上，k₀ = 5 时 64.6% 的 QI 值单独就是稀有的，97.2% 的文档能通过两两组合被唯一定位。剩下 2.8% 是 QI 少于两个的文档。

**发现 4：只看单个 QI 不够。** "只按单值稀有度"让单值稀有率降到 0%，但仍有 95–96% 的文档存在不安全的两两组合。这和 CLAUDE.md 里 TAB pilot 的结论一致，现在在 SAGE 输出上也成立了。

**发现 5：选哪些 QI 比泛化多少更关键。** 用和 ours 完全相同的泛化次数随机分配，风险几乎不降（仍有 91–94%）；ours 用同样的预算把风险降到 0%。

**发现 6：在风险图框架内，节点选择规则的影响很小。**
- 除"随机节点"外，各种选择规则在同一 order 下的信息损失差距都在 4 个百分点以内。
- 在 254 篇语料上，最稀有优先的信息损失最低或并列最低；加权度、考虑代价、前瞻三种在 order 2 下能顺带降低更多三元组风险，但信息损失更高。
- **但在 1,268 篇的 TAB 原标注上，order 3 时加权度在三个 k₀ 下都优于最稀有优先**（62.2 对 64.8、67.2 对 67.7、68.3 对 69.8，见第 6 节）。
- 所以哪种选择规则更好和语料规模有关，**真正起作用的是"风险图 + 迭代覆盖"这个框架本身**。论文的贡献点应该放在框架上，选择规则作为消融。

**发现 7：order 2 和 order 3 是两个隐私等级。** order 2 消除所有两两组合风险，但三元组风险仍有 28–62%。order 3 两者都消除，信息损失多 5–9 个百分点。

## 4. 原文 QI 残留率（LLM 判断）

对每篇文档，把 TAB 原文里人工标注的 QUASI 实体逐个列出来，让 LLM 判断能否从改写后的文本中恢复。

| 语料（k₀ = 5） | 残留率 | 至少残留一个的文档 |
|---|---|---|
| SAGE | **4.29%** | 33.1% |
| 只按单值稀有度 | 0.97% | 18.1% |
| 同样泛化次数随机分配（o3） | 0.82% | 14.6% |
| **ours o2** | **0.80%** | 14.2% |
| **ours o3** | **0.73%** | 12.6% |
| 全部 QUASI 抹掉 | 0.66% | 11.4% |

k₀ = 2 和 10 的结果几乎相同，ours 是 0.70–0.81%。完整表见 `results/sage/residual.csv`。

**发现 8：SAGE 的显式残留不多，但确实存在；ours 基本消除了。**
- 用 DeepSeek 跑的 SAGE 已经去掉了 95% 以上的原文 QI，残留集中在 MISC（20.9%）、DEM（18.0%）和 ORG（7.6%）。
- ours 把残留率降到 0.73%，**已经接近"全部 QUASI 抹掉"的 0.66%**。这个下限来自 QI 抽取没识别出的片段（主要是 DEM、MISC），也就是第 2 节里召回较低的两类。
- 所以**残留率区分不出各泛化方法的好坏**，它更适合用来说明"SAGE 本身不够"。论文的主要隐私指标应该是第 3 节的组合风险。

## 5. 效用：RAG 问答

做法和 SAGE 的评估方式一致：
1. 从原文为每篇生成 2 个问答对，共 508 题。问题针对案情实质，不依赖姓名、案号或具体日期。
2. 对每个语料版本，用 BM25 检索 top-2 文档。
3. LLM 根据检索结果回答，再由 LLM 和参考答案对比打分（1 / 0.5 / 0）。

| 语料 | 问答得分 | 检索命中 @2 | 相对 SAGE 的差异（95% 置信区间，配对 bootstrap） |
|---|---|---|---|
| 原文 | 53.9% | 48.0% | +5.6 [+1.8, +9.4] |
| SAGE | 48.3% | 42.7% | — |
| ours o2，k₀=5 | 47.4% | 42.7% | −0.9 [−3.5, +1.8] |
| **ours o3，k₀=5** | **48.1%** | 42.9% | **−0.2 [−3.0, +2.5]** |
| ours o3，k₀=2 / 10 | 47.3% / 47.1% | 42.5% / 42.1% | −1.0 / −1.2（置信区间都包含 0） |
| 只按单值稀有度，k₀=5 | 46.3% | 41.5% | −2.1 [−4.7, +0.6] |
| 全部 QUASI 抹掉 | 47.3% | 41.5% | −1.0 [−3.6, +1.8] |

**发现 9：泛化隐藏 QI 没有可测的效用代价。** 主要的效用损失发生在 SAGE 改写这一步（−5.6 分，显著）；在 SAGE 之后再做泛化，额外代价在噪声范围内。

**需要注意**："全部 QUASI 抹掉"的效用也只降了 1 分，说明这套问答主要考察案情实质，对 QI 本身不敏感。所以**它能证明"我们的方法不损害 RAG 效用"，但区分不出各泛化方法**。各方法之间的效用差异要用信息损失来体现。如果审稿人要求更细的效用指标，可以加一组依赖时间和地点的问题，比如"申请人被拘留是在哪个年代？"。

图：`results/figures/utility_qa.png`、`results/figures/utility_vs_loss.png`

## 7. SAGE 的 safe 标签与稳健性检验

### 7.1 为什么"没通过 safe"的文档也纳入实验

SAGE 官方代码（`doing_protect.py`）在改写跑满轮数仍未通过时，**不会丢弃该文档**，而是保留最后一次改写结果，照样放进合成文档库。所以 SAGE 实际产出的语料里本来就包含这些文档，我们按 SAGE 的实际输出来研究。

另外，k-匿名是在整个语料上统计的：删掉 32 篇会改变其余文档的组合出现次数，所以纳入或排除是对整个语料的选择。

### 7.2 分组结果（全部 254 篇语料中，k₀ = 5）

| | SAGE 判为 safe（222 篇） | SAGE 判为不 safe（32 篇） |
|---|---|---|
| SAGE 输出的两两组合风险 | **97.7%** | 93.8% |
| SAGE 输出的原文 QI 残留率 | **4.8%** | 0.5% |
| ours（order 2 / 3）后的两两组合风险 | 0% / 0% | 0% / 0% |
| ours（order 3）后的原文 QI 残留率 | 0.77% | 0.39% |

**发现 10：SAGE 的 safe 标签与真实隐私风险无关，甚至方向相反。** 被判为 safe 的文档，组合风险和原文残留都不比不 safe 的低。原因是不 safe 的文档被多改写了几轮，改得更彻底。这说明不能依赖 SAGE 的 LLM 自我审查，需要可量化的检查。ours 对两组都有效。

### 7.3 稳健性：只用 safe 文档作为语料（222 篇，k₀ = 5）

| 方法 | 两两组合风险 | 三元组风险 | 信息损失 |
|---|---|---|---|
| SAGE | 97.7% | 97.7% | 0 |
| ours，order 2 | 0% | 34.2% | 69.5% |
| ours，order 3 | 0% | 0% | 74.0% |

和全部 254 篇的结果（order 2：0 / 46.1 / 68.2；order 3：0 / 0 / 73.6）基本一致，**结论不受是否纳入不 safe 文档影响**。

## 9. 信息损失为什么高，以及敏感性分析

信息损失偏高（ours o3 在 k₀=5 时为 73.6%）有三个原因：

1. **语料小**：254 篇、每篇 14 个 QI，两个具体值同时出现在 5 篇以上的情况本来就少。
2. **严格定义下，泛泛的值也要处理**：比如 "a person"（60 篇）和 "1990s"（100 篇）同时出现的文档可能不到 5 篇，于是 "a person" 也会被抹成 `[PERSON]`。MISC、PERSON、QUANTITY 被 100% 抹掉就是这个原因。
3. **SAGE 写法多样**：同一个意思有很多写法。已经通过规范化处理了一部分（Türkiye/Turkey、"middle of the 1990s"/"mid-1990s" 等），信息损失下降了 5–10 个百分点。

**敏感性分析（ρ）**：按 TAB 标注指南"覆盖大量人群的泛泛属性值可以忽略"的原则，把在 ≥ ρ·N 篇文档中出现的值视为不具识别性。

| ρ（k₀=5，order 3） | 信息损失 | 抹成占位符 |
|---|---|---|
| 不忽略（严格，主结果） | 73.6% | 45.2% |
| 20% | 68.6% | 40.0% |
| **10%** | **59.8%** | **30.0%** |

ρ = 10% 时，order 2 就能同时把两两和三元组风险降到 0%，同样泛化次数的随机分配仍有 94.8% 的风险。主结论不变。结果文件：`results/sage_common10/`

|---|---|---|
| QI 识别 | 在 TAB train 上微调 | LLM few-shot 抽取，在 TAB test 上验证 |
| 图和打分 | GNN（受 DrBC 启发）、风险加权度 | 精确的风险图 + 迭代贪心覆盖；选择规则作为消融（最稀有优先 / 加权度 / 考虑代价 / 前瞻 / 介数中心性） |
| 泛化 agent | 每轮改写文本 | LLM 离线为每个值生成一次泛化层级，循环中确定性上升 |
| 占位符 | 计入组合 | 不计入：占位符只透露"有一个某类实体" |
| 值的规范化 | 只做大小写和标点 | 加入国家别名、时期写法和介词的统一 |

## 11. 局限性（论文中应如实说明）

1. **语料只有 254 篇**。k-匿名统计受语料规模影响大，扩大到 1,266 篇后信息损失应该会明显下降，选择规则的排序也可能改变（TAB 1,268 篇上加权度更好）。
2. **QI 抽取对 DEM 和 MISC 召回低**（原文上 43% 和 22%，SAGE 文本上约 62% 和 63%），这决定了残留率的下限（0.66%）。QI 抽取在 SAGE 文本上的准确率只有间接估计，SAGE 新写出的 QI 尚无人工标准答案。
3. **效用问答集对 QI 不敏感**，只能证明"不损害效用"，不能区分方法。
4. **SAGE 是我们按官方代码重新实现的 ECHR 版**，用的是 DeepSeek 而不是原论文的 GPT-3.5。改写彻底程度可能和原论文不同。
5. **残留率和效用评分都由 LLM 判断**，需要人工验证（材料已准备好，见下）。
6. **威胁模型只覆盖语料内部的显式 QI 组合**，不包括链接回 HUDOC 和"案情模式"本身的可识别性（例如 001-105777 → Heinisch v. Germany），这些留给 EMNLP 2027 的工作。
